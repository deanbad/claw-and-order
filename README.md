# Claw & Order

AI-assisted Discord moderation for the [thelast.io](https://thelast.io) community server. The bot reviews messages in designated public channels, posts possible violations to a staff-only channel, and executes warnings, mutes, or bans only after authorized staff react.

This repository is **proprietary**. It is operated by thelast.io server administration for that community only. It is not a public multi-tenant bot service, and no license is granted to third parties.
